# Privacy Policy

Grok Bot Anywhere is a local desktop client. It does not run a server and does not
collect analytics, telemetry, advertising identifiers, or usage profiles.

## Data stored on your computer

- Grok Bot login credentials are stored in the operating system credential vault
  (macOS Keychain or Windows Credential Manager).
- Bot configuration, drafts, inbox records and delivery status are stored in the
  application's local user-data directory.
- Files shared with the app are copied into that local directory only long enough
  to deliver them.

## Network requests

The app talks to the Grok Bot service using your own account, and to GitHub only
when you explicitly check for updates or use a feature that requires it. Shared
content is sent only to the Bot you select.

## Data sharing

We do not sell, rent, or share personal data. There is no telemetry endpoint.

## Retention and deletion

Local data remains on your computer until you delete it from the app or remove the
application data directory. Uninstalling the app does not automatically delete
that directory.

## Contact

For privacy questions, open an issue at
