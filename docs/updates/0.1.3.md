# Grok Bot Anywhere 0.1.3 更新说明

状态：Current。发布日期：2026-11-05。

0.1.3 把头像引擎更新到 `grok-bot-avatar-engine` 0.1.0（Grok Bot 0.78.1 客户端渲染器移植），补上南瓜头像，并重新校准主 Bot 星标与缺口。macOS 双架构包和 Windows x64 包同时更新。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS Apple Silicon（M1–M4） | `Grok Bot Anywhere-0.1.3-arm64.dmg` |
| macOS Intel | `Grok Bot Anywhere-0.1.3.dmg` |
| Windows 10/11 x64 | `Grok Bot Anywhere-0.1.3-win.zip` |

macOS 两个 DMG 都已做 Developer ID 签名、Apple 公证和 stapler，下载后直接拖进「应用程序」覆盖旧版。覆盖前先完全退出旧版。

Windows 包是**未签名 zip**。解压后如果 SmartScreen 或 Smart App Control 拦截，需要用户自行解除锁定或用自己的证书签名后再运行；公共分发没有代码签名时仍可能被系统拦截。Windows 包没有在 Windows 实机跑过安装验收。

下载与安装步骤见 [Grok Bot Anywhere 下载与使用教程](https://jcng5q8n0f3z.feishu.cn/wiki/HwHmwM4dcidx8Wko50QcJlgGnyd)。

## 头像引擎

- 渲染器换成 0.78.1 客户端移植版：网格投影身体、挖空眼睛、53 个状态。
- 形状表补到 26 个，新增 `pumpkin`；显式南瓜不会再被打回派生形状。
- 南瓜锁橙色，带自己的柄和棱线。
- 其他 25 个形状、11 个颜色和状态映射保持连续；应用层的 light/dark 主题色、PNG 截取和 Touch Bar strip 由适配层接回。
- 微信菜单图标仍然只画头像本身，不带主 Bot 星标。

## 主 Bot 星标

- 星标改为圆角五角星，不再用尖角。
- 位置按身体包围盒计算：直径约为身体宽的 27.6%，圆心在身体宽 87%、高 97% 处。
- 右下缺口跟随星标重新计算，比星标半径多身体宽 5.2% 的间隙。
- 星标比最初版本整体更靠右下，减少对头像图案的侵入。

## Windows

Windows 仍走“下载 zip 后自行处理签名/放行”的方式：

1. 解压 zip 到普通目录，不要直接在压缩包里运行。
2. 如果文件带「来自其他计算机」标记，右键属性里解除锁定，或用 `Unblock-File`。
3. 需要代码签名时，用用户自己的代码签名证书给 `Grok Bot Anywhere.exe` 签名；自签只适合本机或内网，公共分发仍会被 SmartScreen/SAC 拦。
4. 未签名包不会自动更新，升级时重新下载并覆盖。

## 已知范围

- Windows 实机安装、Explorer 右键点击、真实微信转发没有随这一版重新验收。
- macOS Touch Bar 硬件和真实微信发送未随这一版重新验收。
- 两个平台的日志、登录态和收件库仍在原来的用户目录，不会因为覆盖安装而清空。
